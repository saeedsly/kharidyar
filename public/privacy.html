آخرین به‌روزرسانی: ۵ آبان ۱۴۰۵ (۲۷ اکتبر ۲۰۲۶)

دوربین و تصویر فاکتور

دوربین فقط پس از انتخاب شما برای گرفتن عکس فاکتور باز می‌شود. گزینهٔ «OCR ابری OCR.space» به‌صورت پیش‌فرض روشن است: برنامه ابتدا فقط وضعیت سرویس را بررسی می‌کند و اگر سرویس پیکربندی شده باشد، تصویر یا برش‌های لازم را از طریق Supabase Edge Function به OCR.space Engine 3 می‌فرستد. هر فایل حداکثر ۱ مگابایت است؛ برنامه در صورت نیاز آن را کوچک یا فشرده می‌کند و نوشته‌های خیلی ریز ممکن است وضوح کمتری پیدا کنند. سهمیهٔ رایگان Engine 3 تا ۱٬۰۰۰ تبدیل در ماه است؛ هر برش یک تبدیل جداگانه حساب می‌شود و سقف کلی سرویس ۵۰۰ درخواست در روز برای هر IP است. خودِ برنامه تصویر را در سوابق فاکتورها ذخیره نمی‌کند. طبق سیاست حریم خصوصی OCR.space، فایل پس از پردازش OCR حذف و IP درخواست تا یک ماه ثبت می‌شود. برای OCR کاملاً آفلاین، گزینهٔ ابری را خاموش کنید. اگر سرویس پیکربندی نشده یا اینترنت در دسترس نباشد، تصویر برای OCR ابری ارسال نمی‌شود و OCR محلی اجرا می‌شود. اگر سهمیه تمام شده یا سرویس ابری خطا بدهد، برنامه به OCR محلی برمی‌گردد؛ ممکن است تصویر پیش از دریافت خطا به OCR.space فرستاده شده باشد.

پردازش و ذخیره‌سازی

در حالت آفلاین، خواندن متن فاکتور روی دستگاه انجام می‌شود. در حالت ابری، تصویر برای تشخیص متن از طریق Supabase Edge Function به OCR.space فرستاده می‌شود؛ خریدیـار تصویر را در سابقهٔ فاکتورها ذخیره نمی‌کند. متن استخراج‌شده، اقلام، فهرست‌های خرید و بودجه در فضای خصوصی برنامه روی همان دستگاه ذخیره می‌شوند و همگام‌سازی ابری فاکتورها فعال نیست. برای جزئیات پردازش داده، سیاست حریم خصوصی OCR.space را ببینید.

حذف اطلاعات

می‌توانید فاکتورها را جداگانه حذف کنید یا از بخش «حریم خصوصی» همهٔ اطلاعات ذخیره‌شده روی دستگاه را پاک کنید.

نسخهٔ پشتیبان و حذف برنامه

از بخش «پشتیبان» می‌توانید فایل JSON بسازید و در محل دلخواه نگه دارید. حذف برنامه یا پاک‌کردن داده‌های آن در Android ممکن است اطلاعات این دستگاه را نیز حذف کند؛ پیش از آن نسخهٔ پشتیبان بگیرید.

Privacy Policy — KharidYar

Last updated: October 27, 2026

Camera and receipt images

The camera opens only when you choose to take a receipt photo. The OCR.space Cloud OCR toggle is on by default. The app first checks only whether the service is configured; when it is, the image or required image tiles are sent through a Supabase Edge Function to OCR.space Engine 3 for OCR. Each file is limited to 1 MB; the app may resize or compress it, which can reduce detail in very small print. The free Engine 3 allowance is up to 1,000 conversions per month, with each tile counting separately; the service also limits free requests to 500 per day per IP. KharidYar does not save the image in receipt history. According to OCR.space's Privacy Policy, uploaded files are deleted after OCR processing and request IP addresses are logged for one month. Turn Cloud OCR off for fully on-device processing. If the service is unconfigured or there is no internet, the image is not sent for cloud OCR and local OCR is used. If the free allowance is exhausted or the cloud service fails, the app falls back to local OCR; the image may already have been sent to OCR.space before the error is returned.

Processing and storage

With Cloud OCR off, receipt text is read on-device. With it on, the image is relayed through Supabase Edge Function to OCR.space for text recognition; KharidYar does not save it in receipt history. Receipt data, shopping lists, and budgets are stored in the app's private storage on that device, with no receipt cloud sync. For provider-side data processing, see OCR.space's Privacy Policy.

Deleting your data

You can delete receipts individually or erase all data stored on the device from the app's Privacy section.

Backups and uninstalling

You can export a JSON backup from the Backup section and store it wherever you choose. Uninstalling the app or clearing its Android data may remove local information; make a backup first.
