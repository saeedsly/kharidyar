دوربین و تصویر فاکتور

دوربین فقط پس از انتخاب شما برای گرفتن عکس فاکتور باز می‌شود. گزینهٔ «OCR ابری Microsoft» به‌صورت پیش‌فرض روشن است: برنامه ابتدا فقط وضعیت سرویس را بررسی می‌کند و اگر سرویس پیکربندی شده باشد، تصویر یا برش‌های لازم را از طریق Supabase Edge Function برای پردازش OCR به Microsoft Azure Document Intelligence Read می‌فرستد. خودِ برنامه تصویر را در سوابق فاکتورها ذخیره نمی‌کند؛ نحوهٔ پردازش و نگه‌داری احتمالی نزد سرویس‌دهندگان تابع شرایط آن‌هاست. برای OCR کاملاً آفلاین، گزینهٔ ابری را خاموش کنید. اگر سرویس پیکربندی نشده یا اینترنت در دسترس نباشد، تصویر به Azure ارسال نمی‌شود و OCR محلی اجرا می‌شود.

پردازش و ذخیره‌سازی

در حالت آفلاین، خواندن متن فاکتور روی دستگاه انجام می‌شود. در حالت ابری، تصویر فقط برای OCR به سرویس Azure فرستاده می‌شود؛ متن استخراج‌شده، اقلام، فهرست‌های خرید و بودجه در فضای خصوصی برنامه روی همان دستگاه ذخیره می‌شوند و همگام‌سازی ابری فاکتورها فعال نیست. برای جزئیات پردازش داده، سیاست حریم خصوصی Microsoft را ببینید.

حذف اطلاعات

می‌توانید فاکتورها را جداگانه حذف کنید یا از بخش «حریم خصوصی» همهٔ اطلاعات ذخیره‌شده روی دستگاه را پاک کنید.

نسخهٔ پشتیبان و حذف برنامه

از بخش «پشتیبان» می‌توانید فایل JSON بسازید و در محل دلخواه نگه دارید. حذف برنامه یا پاک‌کردن داده‌های آن در Android ممکن است اطلاعات این دستگاه را نیز حذف کند؛ پیش از آن نسخهٔ پشتیبان بگیرید.

Privacy Policy — KharidYar

Last updated: October 27, 2026

Camera and receipt images

The camera opens only when you choose to take a receipt photo. The Microsoft Cloud OCR toggle is on by default. The app first checks only whether the service is configured; when it is, the image or required image tiles are sent through a Supabase Edge Function to Microsoft Azure Document Intelligence Read for OCR. KharidYar does not save the image in receipt history; provider processing and any retention are governed by their terms. Turn Cloud OCR off for fully on-device processing. If the service is unconfigured or there is no internet, the image is not sent to Azure and local OCR is used.

Processing and storage

With Cloud OCR off, receipt text is read on-device. With it on, the image is sent to Azure only for OCR; receipt data, shopping lists, and budgets are stored in the app's private storage on that device, with no receipt cloud sync. For provider-side data processing, see Microsoft's Privacy Statement.

Deleting your data

You can delete receipts individually or erase all data stored on the device from the app's Privacy section.

Backups and uninstalling

You can export a JSON backup from the Backup section and store it wherever you choose. Uninstalling the app or clearing its Android data may remove local information; make a backup first.
