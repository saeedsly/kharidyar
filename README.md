# خریدیـار (KharidYar) 🛒

**مدیریت خرید و چک‌لیست؛ OCR ابری فارسی‌محور با fallback آفلاین روی دستگاه**

- **سازنده و صاحب اثر:** سعید سالاری (Saeed Salari)
- **وب‌سایت پروژه:** [saeedsly.github.io/kharidyar](https://saeedsly.github.io/kharidyar/)
- **سیاست حریم خصوصی:** [Privacy Policy](https://saeedsly.github.io/kharidyar/privacy.html)
- **آخرین APK عمومیِ شناخته‌شده:** [KharidYar-Android7-v1.4.2.apk](https://github.com/saeedsly/kharidyar/releases/download/v1.4.2/KharidYar-Android7-v1.4.2.apk)

## ویژگی‌ها

- ثبت و ویرایش چک‌لیست، فاکتورها و بودجه در حافظهٔ خصوصی برنامه.
- OCR ابری اختیاری با **OCR.space Engine 3** برای متن فارسی/چندزبانه و parser داخلی برای استخراج مبلغ‌ها؛ اگر سرویس خاموش یا در دسترس نباشد، OCR آفلاینِ داخل APK اجرا می‌شود.
- در حالت ابری، تصویر از طریق Supabase Edge Function به OCR.space فرستاده می‌شود؛ تصویر در سابقهٔ فاکتورها ذخیره نمی‌شود.
- گزارش ماهانه بر پایهٔ تقویم شمسی و تجمیع چند فاکتورِ یک روز.
- خروجی و بازیابی پشتیبان JSON از داخل برنامه.
- حالت OCR آفلاین به اینترنت نیاز ندارد. OCR ابری به اینترنت و مجوز عادی INTERNET در Android نیاز دارد؛ با خاموش‌کردن گزینهٔ ابری، تصویر از دستگاه خارج نمی‌شود.

## OCR ابری رایگان

طبق [مستندات رسمی API](https://ocr.space/ocrapi) و [فهرست زبان‌ها](https://ocr.space/languages)، OCR.space Engine 3 از فارسی پشتیبانی می‌کند. تابع ابری برای هر تصویر از `OCREngine=3`، تشخیص زبان خودکار (`language=auto`) و حالت جدولی (`isTable=true`) استفاده می‌کند.

**محدودیت‌های پلن رایگان:** حداکثر **۱ مگابایت برای هر فایل**؛ تا **۱٬۰۰۰ تبدیل با Engine 3 در ماه**؛ و سقف کلی **۵۰۰ درخواست در روز برای هر IP**. هر برشِ رسید بلند یک فایل/تبدیل جداگانه محسوب می‌شود. برای حاشیهٔ اطمینان، برنامه در صورت نیاز نسخهٔ ابری را تا حدود **۹۵۰٬۰۰۰ بایت** کوچک یا فشرده می‌کند؛ فایل اصلی برای fallback محلی دست‌نخورده می‌ماند. فشرده‌سازی یا کوچک‌سازی ممکن است وضوح نوشته‌های خیلی ریز را کاهش دهد. اگر حتی پس از فشرده‌سازی هم حجم بخش از ۹۵۰٬۰۰۰ بایت بیشتر بماند، ارسال نمی‌شود و برنامه به OCR آفلاین برمی‌گردد. پس از اسکن، نام اقلام و مبلغ‌ها را بازبینی کنید؛ دقت OCR تضمین‌شده نیست. سهمیه‌ها ممکن است تغییر کنند.

برای فعال‌سازی، کلید رایگان دریافتی از OCR.space را فقط در **Supabase Dashboard → Edge Functions → Secrets** با نام `OCR_SPACE_API_KEY` ذخیره کنید. کلید را در APK، کد کلاینت، GitHub یا چت قرار ندهید. پس از آماده و ایمن‌شدن تنظیمات Supabase، نسخهٔ جدید Edge Function با نام داخلی `azure-read` منتشر می‌شود؛ این نام برای سازگاری با برنامه‌های نصب‌شدهٔ قبلی حفظ شده، اما تابع جدید به OCR.space وصل می‌شود. نسخهٔ نصب‌شدهٔ ۱٫۴٫۴ فشرده‌سازی اختصاصیِ سقف ۱ مگابایت را ندارد؛ فایل بزرگ‌تر رد می‌شود و برنامه به OCR محلی برمی‌گردد. برای فشرده‌سازی تازهٔ سمت کلاینت، نسخهٔ وب/APK جدید لازم است. تا وقتی secret و نسخهٔ جدید تابع آماده نباشند، تصویر ابری ارسال نمی‌شود و OCR محلی در دسترس می‌ماند.

در حالت ابری، تصویر از دستگاه به Supabase Edge Function و سپس OCR.space می‌رود. طبق [سیاست حریم خصوصی OCR.space](https://ocr.space/privacypolicy)، فایل‌های ارسالی پس از پردازش OCR حذف می‌شوند و نشانی IP درخواست‌ها تا یک ماه ثبت می‌شود. خریدیـار تصویر را در سابقهٔ فاکتور ذخیره نمی‌کند؛ جزئیات بیشتر در [سیاست حریم خصوصی برنامه](https://saeedsly.github.io/kharidyar/privacy.html) آمده است.

**نکتهٔ دسترسی پیش از انتشار:** تابع Supabase فعلاً بدون ورود کاربر کار می‌کند تا برنامهٔ محلی و نسخه‌های نصب‌شده بتوانند آن را صدا بزنند. CORS به‌تنهایی احراز هویت نیست؛ هرکسی که نشانی تابع و کلید عمومی برنامه را داشته باشد ممکن است درخواست بفرستد و سهمیهٔ رایگان OCR را مصرف کند. محدودیت حافظه‌ای فعلی تضمینِ پایدار در برابر سوءاستفاده نیست؛ پیش از فعال‌کردن تابع در دسترس عموم، باید روش محدودسازی و احراز هویت متناسب با استفادهٔ شخصی بررسی شود.

## ساخت نسخهٔ Android

ساخت APK از گردش‌کار GitHub Actions انجام می‌شود. خروجی آن به شکل artifact همان اجرای workflow در دسترس است؛ این روند APK را به‌صورت خودکار در مخزن عمومی یا سرویس ابری منتشر نمی‌کند.

تا زمانی که کلید امضای پایدار در GitHub Actions تنظیم نشده باشد، workflow از کلید موقت استفاده می‌کند و خروجی را `test-only-key` می‌نامد. چنین APKای برای نصب تازه و آزمایش است و نمی‌تواند روی نسخه‌ای با امضای دیگر به‌روزرسانی شود. برای انتشارهای قابل‌به‌روزرسانی باید کلید خصوصی پایدار و امن در GitHub Actions تنظیم شود؛ فایل کلید نباید در مخزن قرار گیرد.
