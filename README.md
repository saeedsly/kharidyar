# خریدیـار (KharidYar) 🛒✨

**اپلیکیشن فول‌استک هوشمند موبایل (Android APK + PWA) و وب برای اسکن فاکتور با بینایی ماشین و مدیریت چک‌لیست ضد فراموشی خرید**

---

## قابلیت‌های کلیدی

1. **اسکنر حرفه‌ای فاکتور با بینایی ماشین چندمرحله‌ای (`Hybrid Computer Vision`)**:
   - **پیش‌پردازش تصویر با OpenCV 5.0**: تشخیص کادر کاغذ فاکتور، حذف سایه دوربین موبایل و تقویت کنتراست جوهر حرارتی (`CLAHE`) با حفظ کامل نقطه‌های حساس حروف فارسی.
   - **خوانش عصبی دوگانه فارسی و عددی (`Dual-Head LSTM Neural OCR`)**: ترکیب موازی شبکه واژگانی فارسی (`fas`) و شبکه دقیق عددی (`fas+eng`) به همراه کنترل خودکار ریاضی مبالغ، تشخیص تاریخ شمسی، تخفیف و جمع نهایی.
   - **پشتیبانی از هوش مصنوعی ابری (`Gemini 2.5 Flash` / `GPT-4o Vision`)**: از طریق Supabase Edge Function (`scan-receipt`).
   - **موتور آفلاین داخلی گوشی**: اجرای مستقل WASM داخل اپلیکیشن اندروید حتی بدون نیاز به روشن بودن سرور.

2. **لیست خرید هوشمند و تطبیق خودکار با فاکتور (`Smart Reconciliation`)**:
   - تعریف لیست خرید قبل از رفتن به فروشگاه و تیک زدن اقلام داخل فروشگاه.
   - به محض اسکن فاکتور صندوق، تمام اقلام خریداری‌شده به صورت خودکار **تیک سبز (✅)** می‌خورند و هر قلمی که فراموش شده باشد در بخش **«از قلم افتاده! ⚠️»** هشدار داده می‌شود.

3. **اتصال ۱۰۰٪ خودکار موبایل، سرور و کلود (`Auto-Discovery Mesh`)**:
   - همگام‌سازی لحظه‌ای (`Realtime WebSockets`) روی دیتابیس ابری **Supabase PostgreSQL 17**.
   - شناسایی خودکار آدرس سرور پردازش تصویر توسط اپلیکیشن اندروید بدون نیاز به وارد کردن دستی IP.

## اجرای محلی سرور و وب‌اپلیکیشن

```bash
npm install
npm run build
npm start
```

سپس برنامه روی آدرس `http://localhost:3000` در دسترس خواهد بود.
